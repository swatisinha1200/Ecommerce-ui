# 🛍️ E-Commerce Website UI

A modern and fully responsive **E-Commerce Website UI** built using **HTML5** and **CSS3**. This project focuses on creating reusable UI components and responsive layouts without using JavaScript.

The goal of this project is to practice and demonstrate core front-end development skills commonly required in interviews and real-world web applications.

---

## 🚀 Features

- Responsive Navigation Bar
- Hero Banner
- Product Categories
- Featured Products
- New Arrivals
- Special Offers Banner
- Customer Testimonials
- Membership Pricing Plans
- Newsletter Subscription
- Shopping Cart UI
- Product Details Page
- User Profile Page
- Orders Page
- Contact Page
- FAQ Page
- Login & Registration Forms
- Responsive Footer
